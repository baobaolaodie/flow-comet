# 工件模板登记册（人类可读版）

> **读者对象**：要核对「某份工件的某一段从哪来」的执行者与审查者——典型场景是段形被判缺时，确认这一段是上游模板段，还是本仓追加的增量段。
> **何时读**：要判定某段的归属、要核对条件段与结构子段的登记、或要确认某个工件的标题形态与首部字段时读它。快照口径与指纹以 `reference/artifact-templates.json` 为准——本册（下称「登记册」）是那张登记表的人类可读派生，登记表增删改后同批更新本册。

## 一、单一来源与派生关系

| 层 | 载体 | 作用 |
|---|---|---|
| 内容权威 | `flow-kit/templates/<DOC>.md` | 段名、段序、正文原文——段集合以它为准 |
| 结构登记 | `reference/artifact-templates.json` | 模板本身推不出的三类信息：条件段、结构子段、增量段；另记首部字段 / 标题形态 / 指纹 |
| 本册 | `reference/artifact-template-overlay.md` | 上面两者的合并读法（供人读；改登记表时同批更新，发版期比对指纹） |

**合并与判定口径**（与引擎同口径，逐条对应报错类别）：

- **段集合以模板为准**：登记表里多出的段（模板已删）忽略并提示；模板里多出的段（登记表未登记）按无条件段处理。
- **段名归一**：忽略编号、括号内容与大小写，核心词必须一致（`## 1. 决策清单` 与 `## 决策清单` 同键）；结构子段里的同名对按括号内容区分（`Button (Primary)` 与 `Button (Secondary)` 不是一段）。
- **无条件段**：缺标题即拦；段正文不得为空。
- **条件段**：**标题必须在场**（缺席即拦）；正文可写 `N/A` / `不适用` / `无` / `—` / `未涉及` / `无变更`，视为已填；与模板该段正文逐字相同判未填。
- **结构子段**：父段在场且父段正文不是整段 `N/A` 时必须在场；父段整段写 `N/A` 则子段豁免。
- **增量段**：不参与模板全序；只校验位置（紧随锚段 / 文末 / 位置不限 / 写在指定段内）。`required` 只由各自门禁消费，本层不做存在性兜底。
- **首部与标题**：标题形态按模板首行（大小写不敏感）；首部只校验已在场的 `- **字段**:` 键的值非空。
- **模板缺席**：整份不校验并输出「未校验（模板缺失）」——不拿内置骨架顶替；标题形态与首部字段来自登记表，照常校验。
- **两阶段报错**：同一工件首次失败只给模板路径与类别计数，再次失败才列段名（记录在 `.specs/<change-id>/.template-hints.json`，通过后清除）。

## 二、逐工件登记

### ARCHITECTURE — `flow-kit/templates/ARCHITECTURE.md`

- 标题形态：`# ARCHITECTURE — 项目级系统架构（活文档）`
- 首部字段：维护者 / 首次创建 / 最近修订 / 当前 ADR 编号最大值
- 无条件段（8）：`1. 系统概览` · `2. 模块清单 + 边界` · `3. ADR 列表` · `4. 跨模块契约` · `5. 扩展点` · `6. 容量 / 性能边界` · `7. 已知技术债 + 长期方向` · `8. 修订历史`
- 条件段：无
- 结构子段：`1.1 一句话定位` · `1.2 服务边界图` · `1.3 关键非功能性指标` · `2.1 模块表` · `2.2 模块依赖规则` · `4.1 公共 HTTP API` · `4.2 事件总线` · `4.3 数据库 schema` · `4.4 共享配置项`
- 增量段：无
- 附加：「ADR 列表」段内的 `### ADR-<数字>` 条目另按条目字段校验（健康巡检与架构沉淀两条侧命令共用同一判据）。

### CHANGE — `flow-kit/templates/CHANGE.md`

- 增量段（1）：`架构层影响声明`（整段，可选，位置 = 文末 / `风险与未知` 之后）

## 三、维护约定

- **改模板 ⇒ 同批改登记表**：段名、段序、结构子段、增量位置任一变化都要同步 `reference/artifact-templates.json`，并在发版期比对指纹（`templateCommit` + 每模板 sha256）；本册同批更新。
- **不得另写段名清单**：门禁一律从登记表 + 模板派生骨架，代码与技能册都不再抄一份段名（抄一份就必然分叉）。
- **本册不是门禁**：它没有运行时消费方——判据落在引擎与登记表；本册只回答「这一段从哪来」。
